# CV Attachments Folder

Place CV files used for outreach attachments in this folder.

## Rules

- File names must match `.env` variable `ATTACHMENTS` exactly.
- Supported formats in the app: `.pdf`, `.doc`, `.docx`.
- Keep files clean and ready to send (final versions only).

## Example

If `.env` contains:

```env
ATTACHMENTS=CV_YourName1.pdf,CV_YourName2.pdf
```

then this folder must include exactly those file names.
